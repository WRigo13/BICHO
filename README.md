# 🎲 Jogo do Bicho — PWA

Acesse: https://wrigo13.github.io/BICHO/

## Arquivos

- `index.html` — app completo (HTML + CSS + JS em um arquivo)
- `manifest.json` — configuração PWA
- `sw.js` — service worker (cache offline)
- `netlify.toml` — configuração Netlify (se migrar)
- `icon-192.png` / `icon-512.png` — adicione os ícones

## Para atualizar no GitHub

1. Edite os arquivos
2. Faça commit e push
3. O GitHub Pages atualiza automaticamente

## Ícones

Adicione dois arquivos PNG na pasta:
- `icon-192.png` (192×192 px)
- `icon-512.png` (512×512 px)

Gere em: https://realfavicongenerator.net
